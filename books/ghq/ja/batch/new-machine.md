# 別のマシンに同じリポジトリをそろえる

新しいマシンに移るとき、リポジトリを一つずつクローンし直すのは手間がかかる。移すのはリポジトリの一覧だけでよい。

古いマシンで、一覧をファイルに書き出す。

```console
$ ghq list > repos.txt
```

新しいマシンで、そのファイルを `ghq get` に渡す。

```console
$ ghq get -P < repos.txt
```

SSH でクローンしたいなら `-p` を足す。

```console
$ ghq get -P -p < repos.txt
```

`ghq get` は、実行したときの設定で置き場所を決める。ルートや URL ごとのルートの設定は、先に新しいマシンの `~/.gitconfig` へ写しておく。ベアリポジトリは一覧に `.git` 付きの名前で出るので、`--bare` を付けて別に渡す（[「`-u` / `--update`: クローン済みのリポジトリを更新する」](../get/update.md)の「ベアリポジトリを除く」）。

## 一覧で移せないもの

一覧から取り直せるのは、リモートにあるものだけである。手元にしかないブランチ、コミットしていない変更、リモートのないリポジトリは移らない。

それらも含めて移すなら、ルートのディレクトリごと `rsync` などでコピーする。`ghq list` はディレクトリをたどって一覧を作るので、コピーしたリポジトリもそのまま一覧に出る。

```console
$ rsync -a old-machine:ghq/ ~/ghq/
```
